## Overview

Observer Mode™ is a behavioral interface experiment exploring how emotional states can change the way digital experiences feel.

Users can switch between four behavioral states:

- Calm
- Focused
- Overwhelmed
- Avoidant

Each state dynamically updates interface styling and messaging to demonstrate how perception can influence interaction.

## Features

- Dynamic state switching
- Interactive behavioral insights
- Custom UI themes for each emotional state
- Responsive layout
- Vanilla HTML, CSS, and JavaScript
